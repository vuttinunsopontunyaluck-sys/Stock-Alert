# Stock Price Target Alert → LINE

แจ้งเตือนราคาหุ้น (ไทย + อเมริกา) ผ่าน LINE เมื่อราคาถึงเป้าหมายที่ตั้งไว้ (สูงสุด 5 เป้าหมาย/หุ้น) แจ้งครั้งเดียวต่อเป้าหมาย

## วิธีติดตั้ง (ทำครั้งเดียว)

1. **สร้าง GitHub repo ใหม่** (private หรือ public ก็ได้) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
   - ต้องมีไฟล์ `.github/workflows/check-prices.yml` อยู่ในตำแหน่งนี้พอดี (GitHub จะอ่าน workflow จากตรงนี้อัตโนมัติ)

2. **สร้าง LINE Messaging API Channel** (ถ้ายังไม่มี ดูขั้นตอนที่คุยกันไปก่อนหน้า) แล้วคัดลอก **Channel Access Token**

3. **ใส่ Token เป็น GitHub Secret**
   - ไปที่ repo → Settings → Secrets and variables → Actions → New repository secret
   - Name: `LINE_CHANNEL_ACCESS_TOKEN`
   - Value: (วาง token ที่คัดลอกมา)

4. **แอด LINE Official Account เป็นเพื่อน** ด้วยแอป LINE ของคุณ (สแกน QR code จากหน้า Console) — จำเป็นเพื่อให้รับข้อความ broadcast ได้

5. เสร็จแล้ว! ระบบจะรันอัตโนมัติทุก 10 นาที ตาม cron ในไฟล์ workflow

## วิธีทดสอบว่าใช้งานได้

ไปที่แท็บ **Actions** ใน repo → เลือก workflow "Check stock price targets" → กด **Run workflow** เพื่อรันทันที ไม่ต้องรอ 10 นาที แล้วดู log ว่าดึงราคาและส่ง LINE ได้ไหม

## วิธีเพิ่ม/แก้ไข/ลบหุ้นและเป้าหมายราคา

แก้ไขไฟล์ `config.json` ได้โดยตรงจากเว็บ GitHub (แม้แต่จากมือถือ): เปิดไฟล์ → กดปุ่มดินสอ (Edit) → แก้ไข → Commit changes

โครงสร้างแต่ละหุ้น:

```json
{
  "symbol": "NVDA",
  "market": "US",
  "yf_ticker": "NVDA",
  "currency": "USD",
  "targets": [
    { "id": 1, "price": 229.90, "condition": "above", "achieved": false }
  ]
}
```

- **symbol**: ชื่อหุ้นที่จะแสดงในข้อความแจ้งเตือน
- **market**: "US" หรือ "TH" (แสดงในข้อความเท่านั้น)
- **yf_ticker**: ticker ที่ใช้ดึงราคาจริง
  - หุ้นอเมริกา: ใส่ตามปกติ เช่น `NVDA`, `AAPL`, `TSLA`
  - หุ้นไทย: ต่อท้ายด้วย `.BK` เช่น `PTT.BK`, `AOT.BK`, `CPALL.BK`
- **currency**: "USD" หรือ "THB"
- **targets**: array สูงสุด **5 รายการ**
  - **id**: หมายเลขเป้าหมาย (1-5) แสดงในข้อความ
  - **price**: ราคาเป้าหมาย
  - **condition**: `"above"` = แจ้งเตือนเมื่อราคาขึ้นถึง/เกินราคานี้, `"below"` = แจ้งเตือนเมื่อราคาลงถึง/ต่ำกว่าราคานี้
  - **achieved**: ปล่อยเป็น `false` เสมอตอนสร้างใหม่ — ระบบจะเปลี่ยนเป็น `true` เองหลังแจ้งเตือนแล้ว และจะไม่แจ้งซ้ำอีก

**เพิ่มหุ้นใหม่**: copy block ทั้งก้อนของหุ้นตัวอย่างไปวางต่อใน array `watchlist` แล้วแก้ค่า

**เพิ่มเป้าหมายใหม่ให้หุ้นเดิม**: เพิ่ม object ใหม่ใน `targets` (ห้ามเกิน 5 รายการต่อหุ้น)

**ลบหุ้น/เป้าหมาย**: ลบ block นั้นออกจาก JSON ได้เลย

## ข้อจำกัดที่ควรรู้

- ราคาจาก `yfinance` เป็นข้อมูลฟรีจาก Yahoo Finance ดีเลย์ประมาณ 15 นาที (ไม่ใช่ real-time แท้ๆ) เพียงพอสำหรับการตั้งเป้าหมายราคาทั่วไป
- GitHub Actions free tier: cron ที่ตั้งไว้ทุก 5 นาทีขึ้นไปใช้ได้ฟรี แต่เวลารันจริงอาจคลาดเคลื่อน/ดีเลย์เพิ่มอีกเล็กน้อยในช่วงที่ระบบ GitHub มีคิวเยอะ
- ข้อความแจ้งเตือนใช้ **broadcast API** (ส่งหาทุกคนที่แอดบัญชี OA เป็นเพื่อน) เหมาะกับกรณีใช้คนเดียว ถ้าจะให้หลายคนรับ ต้องแอด OA เดียวกันทุกคน
- ถ้าต้องการราคาหุ้นไทยแบบ real-time จริง (ไม่ดีเลย์) ต้องเปลี่ยนไปใช้ Settrade Open API ซึ่งต้องมีบัญชีเทรดผูกด้วย — แจ้งได้ถ้าต้องการให้ปรับโค้ดส่วนนี้เพิ่ม

## อยากปรับความถี่การเช็ค

แก้บรรทัด `cron` ในไฟล์ `.github/workflows/check-prices.yml` เช่น
- ทุก 5 นาที: `*/5 * * * *`
- ทุก 30 นาที: `*/30 * * * *`
- เฉพาะเวลาตลาดเปิด (ต้องคำนวณ UTC เอง): เช่น ตลาดหุ้นไทยเปิด 10:00-16:30 ไทย = 03:00-09:30 UTC
